# Cursor Rules for AI

A collection of custom rule sets for the Cursor AI IDE to enhance AI-assisted coding experiences, particularly for Python development.

## Overview

This repository contains carefully crafted instruction sets that guide how the Cursor AI assistant behaves when helping with code. These rules cover Python coding standards, communication style, reasoning approaches, and architectural considerations.

## Contents

- **global-rules.md**: Core rules that apply to all interactions
- **project-specific-rules.md**: Specialized rules for specific project contexts
- **initial-inspiration.txt**: Credit to the original inspiration for these rules

## How to Use

1. Copy the global rules from `global-rules.md` (preferably from the `Raw` view)
2. Paste them in your IDE into `Cursor Settings` >> `Rules` >> `User Rules`
3. For project-specific guidance, refer to the appropriate sections in `project-specific-rules.md`

## Rule Categories

The rules are now organized into two main groups:

### Global Rules
- **Style**: Guidelines for communication and presentation
- **Python**: Best practices for Python 3.10+ development
- **Reasoning and Communication**: Consolidated framework for problem-solving approaches

### Project-Specific Rules
- **Architecture Considerations**: System design and quality attributes
- **Comprehensive Testing**: Testing strategies beyond basic unit tests
- **Legacy Code**: Approaches for working with existing codebases
- **Project Structure**: Organization of Python projects
